# Data

This directory holds raw and processed vibration data. Real datasets are
**not** committed (they are large and license-gated); only small synthetic
demo data is checked in.

## Layout

```
data/
├── raw/
│   ├── cwru/
│   │   ├── synthetic/        # committed — physics-based demo data
│   │   └── <real files>      # gitignored — see "Real data" below
│   └── ims/
│       ├── synthetic/        # committed — physics-based demo data
│       └── <real files>      # gitignored
└── processed/                # gitignored — regenerated by src.preprocessing.run
```

## Synthetic data (committed, used by default)

Generated by `scripts/generate_synthetic.py`, which models bearing defects
as trains of resonance-ringing impacts at the real characteristic
frequencies (BPFO/BPFI/BSF/FTF) computed from published CWRU/IMS bearing
geometry and real CWRU shaft speeds — see
`src/features/bearing_freqs.py` and README section 7.3.

- `data/raw/cwru/synthetic/` — one file per (health state × load), triaxial,
  1 second @ 12 kHz, plus `labels.csv` with ground truth per file.
- `data/raw/ims/synthetic/bearingN/` — a run-to-failure trajectory of short
  snapshots per bearing with growing outer-race defect severity, plus
  `labels.csv` with `rul_cycles` (ground-truth remaining life) per snapshot.

Regenerate (or scale up) with:

```bash
python scripts/generate_synthetic.py \
    --output_dir data/raw \
    --cwru_trials_per_condition 1 \
    --ims_n_bearings 2 --ims_n_snapshots 20
```

This is what CI, the unit tests, and the dashboard's default demo mode run
against. It is explicitly **not** a substitute for the real benchmarks —
see README section 20 (Limitations) — but it exercises every stage of the
pipeline end-to-end with physically consistent signals.

## Real data (not committed)

- **CWRU Bearing Dataset** — download with `python scripts/download_cwru.py
  --output_dir data/raw/cwru`. Source:
  [engineering.case.edu/bearingdatacenter](https://engineering.case.edu/bearingdatacenter).
- **NASA IMS Bearing Dataset** — download with `python scripts/download_ims.py
  --output_dir data/raw/ims`. Source:
  [NASA PCoE data repository](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/).

Both remain the property of their original publishers; consult their
licenses before use. Once downloaded, every script in this repo
(`src.preprocessing.run`, `src.features.extract`, training/eval CLIs) works
identically against real or synthetic data — only `--input_dir` changes.
